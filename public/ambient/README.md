# Quire ambient loops

Local room-sound beds for the built-in themes. Leather still uses `public/windchimes.mp3` (Epidemic Sound, already in the repo).

All three files below are **CC0 / public-domain equivalent** recordings from [BigSoundBank](https://bigsoundbank.com/licenses.html) (Joseph Sardin / Denis Chardonnet). No attribution required; listed here so the desk stays honest.

| File | Theme | Source | License | Notes |
|------|-------|--------|---------|-------|
| `navy-ocean.mp3` | Navy | [Sea Waves with Tern Calls](https://bigsoundbank.com/sea-waves-and-seagulls-s0267.html) (#0267), Denis Chardonnet | CC0 | ~58s loop. Medium shore wash with distant terns (gull-like). Faded edges, −24 LUFS, 160 kb/s stereo. |
| `dark-night.mp3` | Dark | Mix of [Campaign at Night #4](https://bigsoundbank.com/campaign-at-night-4-s1880.html) (#1880, field crickets), [Wind in the Trees](https://bigsoundbank.com/forest-wind-in-the-trees-s0904.html) (#0904), [Tawny Owl #1](https://bigsoundbank.com/tawny-owl-1-s1763.html) (#1763), [Tawny Owl #2](https://bigsoundbank.com/tawny-owl-2-s1764.html) (#1764). Joseph Sardin | CC0 | ~72s. Crickets + soft wind, two quiet hoots. Not horror. −24 LUFS, 160 kb/s stereo. |
| `light-cafe.mp3` | Light | [Coffee Shop at the Capucins](https://bigsoundbank.com/coffee-shop-at-the-capucins-s2561.html) (#2561), Joseph Sardin | CC0 | ~78s trim of the café terrace bed. Room tone and quiet cups; no PA or lyrics. −24 LUFS, 160 kb/s stereo. |

Loudness is matched to sit near `windchimes.mp3` (about −26 LUFS), a little fuller so the new rooms are audible at the same dial.

Processed with ffmpeg (trim / light EQ / fade / loudnorm). Originals were not re-hosted; only these desk-sized loops are shipped.
